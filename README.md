## Описание

Стартап-проект — маркетплейс комиксов от российских авторов. Разрабатывался командой из пяти человек с отдельными ролями: frontend- и backend-разработчики, дизайнер и менеджер проекта.

В рамках проекта:

- спроектирована архитектура клиентского приложения с учётом особенностей Next.js;
- организована работа с серверными данными через API на основе TanStack Query;
- отдельное внимание уделено формам, их валидации, анимациям и организации клиентской логики.

Одна из ключевых частей — личный кабинет, в котором пользователи могут создавать собственные комиксы и размещать их для продажи.
